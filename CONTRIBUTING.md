# Contributing

Thank you for your interest in contributing to this project.

## Basic Workflow

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Test your changes locally
5. Submit a pull request with a clear explanation

## Suggestions for Contributions

- Bug fixes
- Documentation improvements
- Better multilingual OCR handling
- Safer input validation and error handling
- Workflow improvements for research use

## Style Notes

- Keep changes focused and well documented
- Preserve readability for research users who may not be full-time software developers
- Avoid committing credentials, API keys, or private data

## Reporting Issues

When reporting issues, please include:

- Python version
- Operating system
- Example command used
- Whether the target was a local file or URL
- Error message or unexpected behavior
